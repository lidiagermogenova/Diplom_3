# Diplom_3
# Дипломный проект. Часть 3 — UI-тесты для Stellar Burgers

## 📋 Описание проекта
Проект содержит автоматизированные UI-тесты для учебного сервиса [Stellar Burgers](https://stellarburgers.education-services.ru).  
Тесты покрывают основные пользовательские сценарии: регистрацию, авторизацию, работу с конструктором бургеров и личным кабинетом.

## 🚀 Стек технологий
- **Java 11** — язык программирования
- **Maven** — сборка проекта и управление зависимостями
- **JUnit 4** — тестовый фреймворк
- **Selenium WebDriver** — взаимодействие с веб-страницей
- **WebDriverManager** — автоматическая настройка драйверов браузера
- **Allure** — генерация отчётов о тестировании
- **REST Assured** — подготовка тестовых данных через API
- **JavaFaker** — генерация тестовых данных
